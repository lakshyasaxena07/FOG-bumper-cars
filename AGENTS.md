# Repository Agent Guidelines & Rules

## Git Commit Rules
- **No Co-Author Trailers**: NEVER include `Co-Authored-By: Claude ...`, `Co-Authored-By: ...`, or any automated AI attribution trailers in any git commits. Keep commit messages clean and authored solely by the developer.
- **Commit Format**: Use conventional commit messages (`feat: ...`, `fix: ...`, `docs: ...`, `refactor: ...`, `test: ...`).
- **Branch Safety**: Never touch, modify, or push to any git branch other than the currently active branch unless explicitly requested.
